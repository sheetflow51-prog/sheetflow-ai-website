# Approved Governance — Pointer

The governing documents for SheetFlow v2 are **maintained externally in the
founder's Claude CoWork project** and are intentionally *not* stored in this
Git repository.

This directory is a pointer. It holds no document contents by design.

## Governing documents (external, approved, immutable)

- Founder Ratification
- Project Constitution
- North Star
- Truth Matrix
- Decision Register
- Execution Masterplan
- Execution Contract

## Rules

1. These documents are **read-only reference**. They are not reproduced,
   summarised, paraphrased, or reconstructed inside this repository.
2. They are treated as **immutable** unless the founder explicitly approves a
   Decision Register update.
3. Their absence from disk is **expected** and is not a blocker.
4. If implementation conflicts with the Constitution or the Decision Register,
   execution stops and the conflict is escalated to the founder. It is never
   resolved silently.

## Scope note

Milestone definitions (M00, M01, …) live in the Execution Contract. Any
milestone plan proposed inside this repository is a proposal derived from
repository evidence and must be checked against the contract before execution.

## Related in-repo material

Historical research, design, and asset-production material is archived under
`Documentation/Archive/`. It is reference only and carries no governing
authority.

Active operational docs remain at `brand-os/` and `docs/`.
