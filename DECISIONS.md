| Prefix | Meaning |
|---|---|
| `DEC-3xx` | Brand governance. Full records in `brand-os/07_governance/`. |

this way" without a why is not a decision, it is a habit.

## Closed

### DEC-301 — The original PNG is canon
`brand-os/07_governance/DEC-301_LOGO_CANON.md`. `public/logo.png` is the single
source of brand truth. SVG masters are scalability-only approximations and must
never substitute for it on the site, in metadata, or in exports.

### DEC-302 — Brand asset hierarchy
`brand-os/07_governance/DEC-302_BRAND_ASSET_HIERARCHY.md`. `public/brand/` is
**build output**, regenerated by `npm run brand`, never hand-edited. Generators
must measure the source image each run rather than hard-code its bounds — an
inlined pixel bound once made "replace the PNG and rerun" silently false.

### D1 — No unverified customer claim can reach the UI *(resolved)*
Enforcement lives in the type system, not in reviewer discipline.
`src/content/proof.ts` is a discriminated union on `status`; `pending` entries
have **no field to put a metric in**, and only the `published*()` selectors
reach the UI. A Playwright test asserts the removed names never return.

**Why type-level:** a convention that says "don't fabricate" fails the first
time someone is in a hurry. A type that cannot express a fabrication does not.

### D10 — `ink.400` retuned for AA contrast *(resolved)*
`#6B7490` (4.26:1) → `#717B98` (4.81:1 on void, 4.70:1 on glass). Fixed at the
token, so every usage inherited it. Lighthouse accessibility 100; axe reports
zero WCAG 2.1 AA violations in default and reduced-motion paths.

### D13 — `.gitignore` must negate `.env.example` *(resolved 2026-08-06)*
`vercel link` appended `.env*` to the repository root — four lines below a
comment explicitly warning against that exact broadening. It shadowed the
tracked `10_Final_Website/.env.example`, the only documentation of the app's
environment contract.

**Impact:** latent, not active. The file survived because it was already in the
index. A fresh clone adding a new `.env.example` would have lost it silently.

**Resolution:** kept `.env*`, added `!.env.example` / `!**/.env.example`.
Verified by untracking the file and confirming `git status` still lists it —
`git check-ignore -v` is ambiguous with negations and reads as "matched".

This closes the "unattributed edit" half of **D11**.

### D14 — Local MCP servers are project-scoped and committed *(2026-08-06)*
Five stdio servers (`chrome-devtools`, `context7`, `sequential-thinking`,
`playwright`, `filesystem`) plus the remote `github` server are declared in
`.mcp.json` at project scope rather than user scope.

**Why:** the toolchain is part of the project, reviewable in git, and identical
for anyone who clones it. User-scope config is invisible to review and drifts
per machine. Project scope costs one approval prompt per user, which is the
correct security posture for executable config.

Each was verified with a real `initialize` + `tools/list` handshake before
being recorded as installed. `@modelcontextprotocol/server-github` was
**rejected** — npm marks it `Package no longer supported`; the remote server at
`api.githubcopilot.com/mcp/` replaces it.

### D15 — Third-party component registries are declined *(2026-08-06)*
21st.dev, Magic UI, Aceternity, Origin UI, React Bits, Motion Primitives and
HyperUI are **not installed**, despite being available.

**Why:** `brand-os/03_component-language` already defines this project's
component language, implemented against its design tokens. Importing components
built on someone else's tokens forks the design system — precisely the drift
DEC-302 exists to prevent. The constraint here is governance, not capability.

**What would change this:** a genuinely new interaction surface with no
in-house precedent (a command palette, a combobox). Even then, prefer **Radix
primitives** — unstyled behaviour only, no visual opinion, so tokens still
govern appearance.

### D16 — Source maps ship off, and are enabled only for profiling *(2026-08-06)*
`productionBrowserSourceMaps` is gated on `PROFILE_SOURCEMAPS`; `npm run
build:profile` sets it.

**Why this is safe to compare against production:** enabling maps appends a
`sourceMappingURL` comment and writes sibling `.map` files. The JS is otherwise
byte-identical, and browsers never fetch maps unless devtools is open. A
profiling build therefore measures the code production ships.

### D12 — Preview deployments are SSO-protected
Previews return 302 to `vercel.com/sso-api` anonymously. Automated verification

currently runs against the identical production build locally.

### D17 — Which paint effect costs the main thread is unproven *(new, 2026-08-06)*
Profiling established that the decorative motion system causes ~63% of TBT and
**100% of steady-state blocking** (0 ms across 9 reduced-motion runs, spread
0–0), and that `(program)` — paint/layout/composite — is ~65% of main-thread
time.

It did **not** establish which effect is responsible. Four narrower experiments
failed to separate above the noise floor; `no-ambient-anim` scored worse than
baseline, which is physically impossible and proves the arms were noise-bound.

**Leading hypothesis, unconfirmed:** `mix-blend-mode: screen` on the
full-viewport `ambient-sheen` and `plus-lighter` on the cursor glow in
`AmbientBackground.tsx`. Blend modes prevent independent compositing and force
backdrop read-back every frame.

**Next step is measurement, not code:** a paint-level trace via
`chrome-devtools` MCP. A CPU profiler cannot see inside `(program)`.

**Do not** delete animation to win a metric before this is answered.

## Open — needs the founder

### B1 — Portfolio permission *(blocker)*
Three of four named engagements are **corroborated as real**: they are deployed
projects under the founder's own Vercel account, and `sparc-physiotherapy`,
`saraswati-dental-clinic` and `r3s-realty` all return HTTP 200.

**This establishes existence, not permission.** Nothing shows they are paying
clients, that any outcome was measured, or that anyone consented to be named.
Entries stay `pending` and render nothing.

**To unblock, per project:** written permission to name it publicly, plus
either a measured outcome with stated methodology, or agreement to show the work
with no metric attached. The architecture already supports the second case.

Until then `Review` and `AggregateRating` schema stay absent — correctly.

### A1 — Is the Spline/3D direction still live?
`src/components/three/` is imported by no rendered code and the bundle contains
zero Three.js symbols, yet six dependencies exist for it — and their peer
conflict (`drei@9` wants `fiber@^8`, project pins `^9`) is what forces
`--legacy-peer-deps` on every install.

Removing them retires the direction documented in `SPLINE_SCENE_BRIEF.md`, so
it is an architectural decision, not a cleanup. **Resolving it also resolves D6.**

### A2 — Does the cinematic identity survive its measured cost? *(new)*
Follows from **D17**, and only becomes answerable once D17 is.

The motion system is the site's visual signature *and* the dominant source of
main-thread blocking. If the cost turns out to be inherent rather than
attributable to one fixable effect, the trade — signature against battery,
jank and INP — is a founder call under `EXPERIENCE_GOVERNANCE.md`, not an
engineering one.

Framing it early so that, when the trace lands, the decision is already known
to be a design decision.
